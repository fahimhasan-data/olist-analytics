# reports/chapter_notes

One short note per chapter, named `m00.md` … `m12.md`.

Start from [`_TEMPLATE.md`](_TEMPLATE.md). Format (5–8 lines): **Headline → Evidence (numbers) → Action → Risks**, plus one line on what was hard for you. See the story format in [`docs/SQL_PROBLEM_BANK.md`](../../docs/SQL_PROBLEM_BANK.md).

Also add a dated entry to [`../learning_log.md`](../learning_log.md) when a chapter is finished.
